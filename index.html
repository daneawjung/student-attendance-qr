🧭 เมนูจัดการระบบ

เลือกงานที่ต้องการทำ โดย Dashboard ใช้สำหรับการทำงานประจำวัน

⚙️จัดการภาคเรียนตั้งภาคเรียนปัจจุบัน 📚จัดการรายวิชารายวิชาและการรับนักเรียน 👨‍🎓รายชื่อนักเรียนเพิ่มและแก้ไขข้อมูลนักเรียน 📋ลงทะเบียนนักเรียนจัดนักเรียนเข้ารายวิชา 📅ตารางเรียนประจำตารางที่ใช้ซ้ำทุกสัปดาห์ 👀ดูตารางรายสัปดาห์ดูภาพรวมตารางสอน ➕เพิ่มคาบเรียนพิเศษคาบชดเชยหรือนอกตาราง 📥นำเข้ารายชื่อนักเรียนเพิ่มข้อมูลจำนวนมาก 📊รายงานการเข้าเรียนรายวันและรายสะสม

🔗 เส้นทางการทำงาน

จัดการภาคเรียน → รายวิชา → ลงทะเบียนนักเรียน → ตารางเรียนประจำ → เปิดคาบ → QR → นักเรียนเช็กชื่อ → ครูตรวจ/แก้สถานะ → ปิดคาบ → รายงาน

ถ้ามีคาบชดเชยหรือนอกตาราง ให้ใช้ เพิ่มคาบเรียนพิเศษ โดยไม่ต้องแก้ตารางเรียนประจำ
